# Contributing to GreenLand

Thank you for considering contributing to GreenLand! We're excited to have your input in building a better and greener future for industrial and maritime documentation.

---

## How to Contribute

### 1. Fork This Repository
- Start by clicking the "Fork" button at the top right of the repository page.
- This creates your own copy of the repository under your GitHub account.

### 2. Clone the Repository
After forking, clone your copy to begin working locally:

```bash
git clone https://github.com/YOUR-USERNAME/GreenLand.git
```

### 3. Create a Branch
To avoid conflicts, create a new branch for your work:

```bash
git checkout -b feature-your-feature-name
```

### 4. Make Your Changes
- Focus your contributions on the project’s focus areas.
- Make incremental commits for better tracking:

```bash
git add <changed-file>
git commit -m "Your explanatory commit message"
```

> Avoid `git add .` — it can accidentally stage sensitive files such as `.env` or local config. Always add files by name so you know exactly what is going into the commit.

---

## Pull Request Workflow

### 1. Push Changes to GitHub
Once satisfied with your changes, push your branch back to your fork:

```bash
git push -u origin feature-your-feature-name
```

### 2. Open a Pull Request
Navigate back to the GreenLand repository and click on:
- "Compare & pull request."

### 3. Follow Submission Guidelines
- Explain your changes: problem solved or value added.
- Include images/videos if relevant for documentation improvements.

---

## Contribution Standards

### Formatting:
- Make all textual content concise and professional.
- Check spelling, grammar, and structure consistency.

### Code Quality:
- Maintain clean, readable code.

### Documentation:
- Always update the README, or relevant docs, if applicable.

---

## Code of Conduct
Our project is committed to fostering an inclusive, kind, and respectful environment for everyone. Kindly adhere to principles of respect and collaboration outlined in our [Code of Conduct](CODE_OF_CONDUCT.md) in every contribution.
